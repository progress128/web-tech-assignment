# ICT251 Activity 3 - Interactive Personal Portfolio

This repository contains the interactive student portfolio for ICT251 Web Technologies.

## Project Structure
- `index.html` - Main HTML5 portfolio document
- `css/style.css` - Custom styling and dark mode rules
- `js/script.js` - Interactive JavaScript functionality
- `images/` - Image assets
- `videos/` - Audio and video media files

## JavaScript Features Included
1. **Contact Form Validation & Local Preview (Compulsory):** Validates required input fields and displays a summary on the page without reloading.
2. **Expandable Content:** Toggle buttons to show and hide detailed project descriptions.
3. **Theme Switcher:** Light and Dark mode toggle for the entire layout.
4. **Study Hours Calculator:** Accepts planned daily hours and days per week to output weekly total study time with input validation.
